# @lyteboat/serve

lyteboat's service bundle over dsh-base: serve every agent of the --agents directories over HTTP (POST /chat, GET /agents, GET /health) through dsh's session controller.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/bundles/serve`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/bundles/serve); the repository README explains how the packages fit together and how a project outside the repository installs them.

# @lyteboat/eval

lyteboat's eval bundle over dsh-base: run an agent's eval cases through dsh's session controller, record them, replay them without a model, and compare two runs.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/bundles/eval`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/bundles/eval); the repository README explains how the packages fit together and how a project outside the repository installs them.

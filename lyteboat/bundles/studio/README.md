# @lyteboat/studio

lyteboat's Studio workshop bundle over dsh-base and @lyteboat/base: the agents of the --agents directories inspected without running a session, behind Studio's own sign-in and roles, on /api/studio; `lyteboat studio account` manages the accounts.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/bundles/studio`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/bundles/studio); the repository README explains how the packages fit together and how a project outside the repository installs them.

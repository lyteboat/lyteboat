# @lyteboat/inspect

lyteboat's inspect bundle over dsh-base: mount one agent the way the business modes do and print what it is made of (its tools and how each reaches the model, its skills and their checks, its eval case files), or why it did not mount.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/bundles/inspect`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/bundles/inspect); the repository README explains how the packages fit together and how a project outside the repository installs them.

# @lyteboat/base

lyteboat's business base over dsh-base: lyteboat's host services (distro marker, tool policy, side calls, request context, turn outcome, admission, skill router, a2ui, history import), and a business agent gets only the capabilities its own composition declares, so the coding tools and the services behind them, the sandbox and approval rows, the host's skill roots, and the rows that leak the machine's configuration into model requests are off in every business mode (serve, eval, studio, inspect).

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/bundles/base`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/bundles/base); the repository README explains how the packages fit together and how a project outside the repository installs them.

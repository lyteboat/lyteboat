# @lyteboat/contracts

lyteboat's contract extensions over the dsh seams: tool and skill metadata, the kernel's lyteboat/* step events, log nodes, projection keys, and the zod schemas of the JSON envelopes lyteboat writes.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/core/contracts`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/core/contracts); the repository README explains how the packages fit together and how a project outside the repository installs them.

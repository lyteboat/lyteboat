# @lyteboat/cli

The lyteboat launcher: profile templates, patch stack, and boot over the official DeepSeek Harness packages.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/apps/cli`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/apps/cli); the repository README explains how the packages fit together and how a project outside the repository installs them.

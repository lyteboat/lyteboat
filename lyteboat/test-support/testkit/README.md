# @lyteboat/testkit

lyteboat's test harness: the unit host (dsh's invariants, the dsh services, the kernel's agent loop) and the in-process MockAdapter for unit tests, in-process composition boots for bundle and agent tests, per-file scratch homes and workspaces, the session-log reader and its reopen check, the scripted DeepSeek Messages model, a /chat client, and launcher spawning for e2e tests.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/test-support/testkit`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/test-support/testkit); the repository README explains how the packages fit together and how a project outside the repository installs them.

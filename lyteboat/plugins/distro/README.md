# @lyteboat/distro

lyteboat's distribution marker: the lyteboatDistro service naming the dsh release lyteboat's kernel was imported from and the kernel extensions it carries.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/distro`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/distro); the repository README explains how the packages fit together and how a project outside the repository installs them.

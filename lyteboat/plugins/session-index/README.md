# @lyteboat/session-index

lyteboat's session index: an agent's stored sessions listed, searched, folded into a timeline, and read as stored, through read handles that never take a session's write ownership.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/session-index`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/session-index); the repository README explains how the packages fit together and how a project outside the repository installs them.

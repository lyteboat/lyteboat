# @lyteboat/agent-definition

lyteboat's business-agent definition: lyteboatAgentDef({…}) checks one declaration (identity, persona, skills, skill routing, tool policy, model request overrides, tools, admission, the render_a2ui tool, event listeners) and returns the one row an agent directory mounts in the agent's standing scope, which hands each declaration to the host service that owns it.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/agent-definition`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/agent-definition); the repository README explains how the packages fit together and how a project outside the repository installs them.

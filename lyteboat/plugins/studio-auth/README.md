# @lyteboat/studio-auth

lyteboat Studio's sign-in: operator-managed accounts (scrypt), admin/editor/viewer role grants, signed bearer tokens, and gateway mode.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/studio-auth`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/studio-auth); the repository README explains how the packages fit together and how a project outside the repository installs them.

# @lyteboat/turn-metrics

lyteboat's turn metrics: the recorder a service mounts (one line per turn in a UTC day file, from the turn's outcome, and a heartbeat file of the running turns) and the reader the Studio mounts.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/turn-metrics`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/turn-metrics); the repository README explains how the packages fit together and how a project outside the repository installs them.

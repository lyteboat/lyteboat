# @lyteboat/request-admission

lyteboat's admission at the first step of each turn: an agent registers an admission function, which the service runs on the turn's human message on the lyteboat/intake waterfall; a reply verdict answers the turn without a model request and logs the message with the verdict on its request.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/request-admission`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/request-admission); the repository README explains how the packages fit together and how a project outside the repository installs them.

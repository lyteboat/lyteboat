# @lyteboat/a2ui

lyteboat's A2UI template engine (a port of the reference template mode: manifest resolution, transforms DSL, walker, contract validation) and the render_a2ui tool that folds rendered cards into the lyteboatCards projection.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/a2ui`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/a2ui); the repository README explains how the packages fit together and how a project outside the repository installs them.

# @lyteboat/skill-router

lyteboat's skill router over the dsh skill registry: full / dynamic load modes, LLM routing per user input (the reference LLMSkillRouter), the lyteboatActiveSkill projection, and required-tool activation through @lyteboat/tool-policy.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/skill-router`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/skill-router); the repository README explains how the packages fit together and how a project outside the repository installs them.

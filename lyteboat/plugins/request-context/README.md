# @lyteboat/request-context

lyteboat's request context: the request a human message answers to (request id, context, admission verdict) rides the message's own source, and the lyteboatRequest projection keeps the session's context.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/request-context`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/request-context); the repository README explains how the packages fit together and how a project outside the repository installs them.

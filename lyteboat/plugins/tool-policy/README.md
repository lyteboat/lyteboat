# @lyteboat/tool-policy

lyteboat's tool policy over the dsh tool registry: visibility (always/auto + activation, and whether an agent's undeclared inherited tools stay visible) and tool-result state deltas folded into the lyteboatState projection.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/tool-policy`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/tool-policy); the repository README explains how the packages fit together and how a project outside the repository installs them.

# @lyteboat/agent-inspector

lyteboat's agent inspector: an agent's tools (what reaches the model and how), skills, and skill routing, read from its standing scope without creating an agent instance or writing to disk.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/agent-inspector`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/agent-inspector); the repository README explains how the packages fit together and how a project outside the repository installs them.

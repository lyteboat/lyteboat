# @lyteboat/studio-api

lyteboat Studio's HTTP API under /api/studio on the host web server: the Host allowlist and security headers, sign-in, role checks, users, the system page, and the agent radar, with an audit log of every change.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/studio-api`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/studio-api); the repository README explains how the packages fit together and how a project outside the repository installs them.

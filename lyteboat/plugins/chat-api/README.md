# @lyteboat/chat-api

lyteboat's /chat endpoint on the host web server: a caller's message reaches an agent through dsh's session controller with its request on the source, after the history it brings is queued as turns of their own, and the answer returns as JSON or an enterprise event stream with cards placed.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/chat-api`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/chat-api); the repository README explains how the packages fit together and how a project outside the repository installs them.

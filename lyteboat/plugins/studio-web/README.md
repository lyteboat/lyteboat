# @lyteboat/studio-web

lyteboat Studio's pages: a React single-page app (src/client) built into lib/web and served at /studio on the host web server under a strict CSP.

Part of [lyteboat](https://github.com/lyteboat/lyteboat), an agent harness for business agents built on DeepSeek Harness. Its source is [`lyteboat/plugins/studio-web`](https://github.com/lyteboat/lyteboat/tree/master/lyteboat/plugins/studio-web); the repository README explains how the packages fit together and how a project outside the repository installs them.
